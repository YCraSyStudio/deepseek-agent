# Decisions

This section records why the extension is built the way it is. Each record states the context, the decision and its consequences, so a later change can be compared with the choice it replaces.

Design decisions in [design](design/2.INDEX.MD) cover architecture, persistence and runtime behavior. Development decisions in [develop](develop/2.INDEX.MD) cover the toolchain, tests, documentation and release process.
