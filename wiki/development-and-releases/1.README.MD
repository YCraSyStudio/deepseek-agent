# Development and Releases

Use this section to make, verify and publish a change. Read the [decisions](decisions/2.INDEX.MD) for the rationale behind the architecture, toolchain, tests and releases, then the [conventions](conventions.md) before editing code or documentation. Use the [build and test scripts](scripts.md) and [verification checklist](verification.md) to check the result.

The extension build uses esbuild for `dist/extension.js` and Vite for `dist/webview/`. The public documentation site in `web-doc/` uses Astro and has its own build.

See [diagnostics](diagnostics.md) to investigate runtime failures and [release channels and publishing](beta-publishing.md) to prepare a beta or stable release. For where to place a change, see the [repository map](../architecture/repository-structure.md).
