# Commands and Views

## Commands

| Command | Where it appears | Behavior |
| --- | --- | --- |
| `deepseek-agent.openChat` | Command Palette | Opens or focuses the YCraSy DeepSeek Agent sidebar and resolves `deepseek-agent.chatView`. |
| `deepseek-agent.addFileToChat` | Explorer context menu, editor context submenu, Command Palette | Adds up to 50 selected files to the current draft. Files outside the workspace become read-only snapshots, limited to 1 MiB; potentially sensitive names require confirmation. |
| `deepseek-agent.addSelectionToChat` | Editor context submenu when a selection exists, Command Palette | Adds the active selection with its file, line range and language. Selections over 1 MiB are refused. |
| `deepseek-agent.newChat` | Command Palette | Starts a new conversation in the sidebar. |
| `deepseek-agent.reviewChanges` | SCM title, editor context submenu, Command Palette | Collects staged and unstaged Git diffs from every local workspace root, sets the draft “Review these workspace changes.” and attaches a `git.diff` reference up to 1 MiB. Reports when there are no changes or no local folder. |
| `deepseek-agent.showDiagnostics` | Command Palette | Opens the extension diagnostics output. |
| `deepseek-agent.clearDiagnostics` | Command Palette | Clears the diagnostics output. |
| `deepseek-agent.completeEditor` | Editor context submenu → YCraSy DeepSeek Agent, Command Palette | Generates a completion for the selection or surrounding block and opens a native diff with Apply/Discard. Requires beta features. See [editor assistance](editor-assistance.md). |
| `deepseek-agent.refactorEditor` | Editor context submenu → YCraSy DeepSeek Agent, Command Palette | Refactors the selection or surrounding block through the same preview flow. Does not require beta features. |
| `deepseek-agent.revertReviewedTurn` | Editor title of a `ycrasy-change` diff | Reverts the reviewed turn after the normal recovery checks. See [workspace recovery](../tools-and-permissions/workspace-recovery.md). |

## Views and menus

- Activity bar container `deepseek-agent-sidebar`, titled **YCraSy DeepSeek Agent**, with icon `src/assets/DeepSeekIcon.svg`.
- Webview view `deepseek-agent.chatView`, named **Chat**, visible by default.
- Submenu `deepseek-agent.editorActions`, labeled **YCraSy DeepSeek Agent**, grouping Complete, Refactor, Add Selection and Review Changes.
- Explorer context entry is limited to file resources; the editor submenu requires text focus and a writable editor; the revert action is limited to the `ycrasy-change` scheme.

The main React webview renders Chat, History and Settings from HTML generated by `WebviewProvider` and assets in `dist/webview`.

## Path and instruction autocomplete

Typing `./` in the composer opens workspace paths and reusable instructions:

- `../` never opens autocomplete and is rejected if sent manually.
- A folder is inserted without a trailing slash, for example `./src`. Its children appear only after the user types `/`; selecting a folder closes the picker.
- Multiple workspace roots are addressed by alias, such as `./frontend`.
- Suggestions are grouped into Files and Instructions; instructions are split into Workspace and Global.
- Selecting an instruction inserts a reference such as `./@instructions/global/commit.md`. The host validates it against the chat workspace and reads the saved file; at most eight instructions and 128 KiB total apply to one turn.

## Removed approaches

- The separate drop zone view was removed.
- Explorer copy/paste integration was not kept because VS Code does not expose copied Explorer URIs to webviews as normal clipboard data.
- Workspace context can be entered through `./` autocomplete, Explorer/editor commands, or the unified native attachment button. The same picker routes JPEG, PNG, GIF and WebP images to DeepSeek's Files API and turns other external files into temporary read-only snapshots. Images can also be pasted with `Ctrl+V`/`Cmd+V`; separate tool access still follows the active permission mode.
