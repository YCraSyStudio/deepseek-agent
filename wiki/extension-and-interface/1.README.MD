# Extension and Interface

The entry point in `src/Extension.ts` delegates lifecycle and composition to `src/extension/`. The VS Code host adapters in `src/vscode/` register commands and views, receive webview requests and connect handlers with workspace access, settings, history, DeepSeek and tools.

The React app in `src/ui/` renders Chat, History and Settings. It sends requests through `vscodeApi` and renders streaming, reasoning, tool results, confirmations and attachment previews. The host uploads and caches attachments and returns protocol-safe metadata.

See the [message contract](message-contract.md) when a feature crosses the host and webview boundary. See the [runtime flow](../chat-and-models/runtime-flow.md) to follow a request through a generation.
