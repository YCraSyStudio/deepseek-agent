# Chat and Models

Start with the [runtime flow](runtime-flow.md) to follow a message from the composer through queueing, context preparation, streaming and completion. The same page covers steering, cancellation and how a generation starts a tool call.

The provider adapter in `src/infrastructure/deepseek/` builds DeepSeek requests, processes streaming responses, maps provider errors and manages image attachments through the Files API.
