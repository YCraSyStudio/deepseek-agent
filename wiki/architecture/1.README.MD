# Architecture

The extension uses layers to isolate VS Code, DeepSeek, the webview and domain logic. Use the [repository structure](repository-structure.md) to locate an existing feature or decide where to add one. The [layers](layers.md) and [dependency rules](dependency-rules.md) describe what each layer owns and which dependencies it may take. The constraints behind those boundaries are recorded under [design decisions](../development-and-releases/decisions/design/2.INDEX.MD).

For a walkthrough across layers, see [what happens when a chat message is sent](../chat-and-models/runtime-flow.md#user-message).
